# Projeto 1º Semestre - DSM FATEC

Iremos implementar um sistema CRM para cadastro e acompanhamento de vagas de emprego.

Nele o usuário irá cadastrar as vagas para qual ele aplicou, com algumas informações como: 

- Nome da Vaga
- Nome da Empresa 
- Link para a vaga
- Data de aplicação

Esses são alguns exemplos, podendo haver mais campos.
